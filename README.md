# SageLoom

SageLoom is a distributed data integration engine for real-time processing and auto-scaling across hybrid cloud and on-premises platforms.

With SageLoom, you get a lightweight tool that stays out of your way.

**What you get**

- SageLoom is a distributed data
- integration engine for real-time processing
- and auto-scaling across hybrid cloud

## Installation

1. Clone the repository: `git clone https://github.com/minjukimdev/SageLoom.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

SageLoom is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
